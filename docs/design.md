# TBMWAR — מסמך עיצוב מפורט
## גרסה v20260518a

---

## 1. סקירה כללית

TBMWAR הוא סימולטור טקטי לדו-קרב בין מערכות הגנה מפני טילים בליסטיים (BMD) לבין מתקפות טילים. המשחק מציג שני תרחישים:

- **אתגר הגנה**: השחקן מפרס מיירטים ומכ"מים ועליו לעצור מתקפה בליסטית
- **אתגר התקפה**: השחקן בוחר טילים, נקודות שיגור ויעדים בניסיון לחדור הגנה

---

## 2. מנגנון טיסה בליסטית

### משוואת הגובה

```
h(t) = 4 · H_max · t · (1 - t)
```

כאשר:
- `t ∈ [0, 1]` = שבר מסלול (0=שיגור, 0.5=שיא, 1=נחיתה)
- `H_max = range_km × 0.18` (קילומטרים)

### מיקום אופקי

```
x(t) = x_launch + t · (x_target - x_launch)
y(t) = y_launch + t · (y_target - y_launch)
```

### פאזות טיסה וצבעים

| פאזה | t | צבע |
|------|---|-----|
| עלייה | 0–0.4 | כחול #5fc8e8 |
| שיא | 0.4–0.6 | לבן #ffffff |
| ירידה | 0.6–0.85 | כתום #f97316 |
| גישה סופית | 0.85–1.0 | אדום #ef4444 |

### ויזואל

- **גודל סמל**: `radius = 4 + h(t) / H_max × 8` (פיקסלים)
- **קו צל**: קו מקווקו אנכי מהסמל לרצפת הקנבס, אטימות 30%
- **תווית גובה**: `Math.round(h(t))` km מוצג מעל הסמל
- **זנב**: 8 נקודות אחרונות של המסלול, אטימות יורדת

## 7. תרחיש הגנה — זרימת משחק

```
1. בחרת קושי
2. פריסה (Deployment Phase):
   - תקציב ראשוני: קל=50, בינוני=40, קשה=30, קשה-במיוחד=25
   - בחר מיירטים ומכ"מים, מקם על המפה
3. סימולציה:
   - גלי מתקפה עם ספירה לאחור בין גלים
   - מיירטים שוגרים אוטומטית כשטיל נכנס לחלון יירוט
4. תוצאות:
   - ציון = (יעדים ניצולו / סה"כ יעדים) × 100
   - בונוס על תקציב שנחסך
```

### יעדים
6 יעדים קבועים על המפה:
- בסיס צבאי (ערך 30)
- עיר גדולה (ערך 25)
- תחנת כוח (ערך 20)
- נמל תעופה (ערך 15)
- מתקן תעשייתי (ערך 10)

---

## 8. תרחיש התקפה — זרימת משחק

```
1. בחרת קושי
2. תכנון:
   - תקציב: קל=30, בינוני=25, קשה=20, קשה-במיוחד=15
   - בחר טילים + נקודות שיגור + יעדים
   - בקושי noIntel: מיירטי האויב נסתרים (לא רואים פריסה)
3. סימולציה:
   - מיירטי האויב שוגרים אוטומטית
4. תוצאות:
   - ציון = (פגיעות / סה"כ טילים) × 100
   - בונוס על יעדים בעלי ערך גבוה
```

---

## 9. מערכת ציונים

```
ציון הגנה = Σ(ערך יעדים ניצולו) / Σ(ערך כל היעדים) × 100
ציון התקפה = Σ(ערך יעדים שנפגעו) / Σ(ערך כל היעדים) × 100
```

| ציון | דירוג |
|---|---|
| 90–100 | ★★★ מצוין |
| 70–89 | ★★☆ טוב |
| 50–69 | ★☆☆ בינוני |
| 0–49 | ☆☆☆ כישלון |

## 11. מפה ויזואלית

- **רקע**: #080d18 עם גריד דק בגוון כחול (#1a2744)
- **קווי גריד**: כל 100km (מחושב לפי סקאלת המפה)
- **יעדים**: אייקוני SVG בצבע ירוק עם הילה
- **נקודות שיגור**: משולש אדום
- **מיירטים**: מעגל כחול עם מעגל טווח (stroke מקווקו)
- **מכ"מים**: שני קשתות גלים בצבע ירוק בהיר
- **טילים בטיסה**: עיגול + זנב + צל אנכי + תווית

## 12. הנפשות ואפקטים

- **פיצוץ**: 20 חלקיקים מתפשטים, אפקט flash, radius גדל ונעלם
- **יירוט מוצלח**: פיצוץ ירוק + הודעת "נוטרל"
- **פגיעה ביעד**: פיצוץ אדום + הודעת "נפגע" + יעד מסומן ×
- **שיגור מיירט**: אפקט בזק מנקודת הפריסה
- **שיגור טיל**: עשן קצר מנקודת השיגור

## 13. Scrubber (חזרה על סימולציה)

- מופיע אחרי הסתיים הסימולציה
- ציר זמן הורינזטלי עם נקודות מפתח
- כפתורי ▶ / ⏸ / ◀◀ / ▶▶
- מהירות: ×0.5, ×1, ×2, ×4
- לחיצה על ציר הזמן ← קפיצה לנקודה
